# Журнал изменений

Публичный журнал выпущенных исправлений и обновлений senatorovai-lab, упомянутый в [регламенте обработки заявок](README.md#регламент-обработки-заявок). Здесь фиксируется, что именно исправлено, когда это выехало на `lab.senatorovai.com`, и какие обращения из этого репозитория это закрывает.

Основной код проекта находится в приватном репозитории `senatorovai-lab` — ссылки на коммиты ведут туда и доступны участникам с доступом к нему; здесь важен сам факт и описание исправления.

## 2026-10-07

- **Индикация верного/неверного ответа есть у всех типов заданий.** Раньше после правильного/неправильного ответа для «заполните пробелы» не показывалось никакой подсказки, а у остальных типов заданий под цветной рамкой с результатом дублировалась отдельная избыточная панель с результатами тестов. Теперь у всех типов заданий (один ответ, несколько ответов, сопоставление, сортировка, заполнение пропусков, текстовый ответ) одинаковая цветная рамка + текст результата, без дублей. Закрывает [#7](https://github.com/SENATOROVAI/senatorovai-lab-support/issues/7). (`23d3522`, `8ef2a76`, `6421f59`)
- **Панель «Сабмишены» больше не задваивает попытки.** Каждая проверка ответа создавала два события в базе, и панель показывала по одной строке на каждое — то есть каждая реальная попытка студента отображалась дважды (а для notebook-заданий дубль всегда показывал статус «не проверено» независимо от реального результата). Теперь одна попытка — одна строка. (`55b4a0a`)
- **Задания «заполните пробелы» снова показывают содержимое.** Импортированные из Stepik задания этого типа хранят текст и поля для ответа отдельно от заголовка; интерфейс выводил только заголовок, из-за чего сам вопрос был не виден. Добавлен рендер текста и полей ответа (включая выпадающие списки с вариантами), сохранение и проверка ответов на несколько пропусков по отдельности. Закрывает [#5](https://github.com/SENATOROVAI/senatorovai-lab-support/issues/5). (`f7dd6da`, `0683951`)
- **Убран бейдж «Предпросмотр черновика» у опубликованных курсов.** У преподавателей интерфейс показывал статус курса из локально закэшированной копии контента, где у всех импортированных курсов стоял флаг черновика ещё со времён первоначального импорта — независимо от реального статуса публикации. Флаг приведён в соответствие с реальным статусом курсов. (`f168549`)
- **Страница больше не зависает на старой версии после обновления сайта.** Главная HTML-страница отдавалась без заголовков кэширования, из-за чего браузер мог молча показывать версию до последнего обновления. Теперь она всегда перезапрашивается заново при каждой загрузке. (`38371bf`)
